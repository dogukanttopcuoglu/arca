# Triage labels

The five canonical triage roles, each label string equal to its name. Applied by the `triage` skill when moving issues through its state machine; `to-spec` applies `ready-for-agent` on publication.

| Role | Label string |
|------|--------------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Wontfix | `wontfix` |
